# Product Requirements Document (PRD)
## InvoicePro — Receipt & Invoice Generator

**Version:** 1.0.0  
**Date:** May 2026  
**Status:** MVP Release

---

## 1. Product Overview

**InvoicePro** is a modern, browser-based billing web application that enables freelancers, creators, small businesses, and vendors to generate professional invoices and receipts from a single, streamlined workspace.

### Vision
Make financial documentation fast, trustworthy, and accessible to anyone — regardless of technical skill level.

### Problem Statement
Freelancers and small business owners typically struggle with:
- Slow, template-heavy invoice creation
- Losing track of who has paid and who hasn't
- No easy way to generate receipts for paid invoices
- Managing multiple clients' billing information scattered across tools

### Solution
A lightweight, fully client-side web app that handles the complete invoicing lifecycle from creation to receipt — with no subscriptions, servers, or complex configuration required.

## 3. Core User Stories

### Authentication
- As a user, I want to create an account with my email so my financial records are private and persistent
- As a user, I want to log in with saved credentials so I can access my data on return visits
- As a user, I want a demo account to explore the app before committing

### Invoice Management
- As a user, I want to create an invoice with my client's details, line items, and pricing
- As a user, I want the app to auto-calculate subtotals, tax, and totals
- As a user, I want to save invoices as drafts before sending
- As a user, I want to mark invoices as "Sent" to track their status
- As a user, I want to mark invoices as "Paid" when payment is received
- As a user, I want overdue invoices automatically flagged when they pass the due date
- As a user, I want a unique, auto-incrementing invoice number (INV-001, INV-002…)

### Receipt Generation
- As a user, I want paid invoices to be instantly convertible into receipts
- As a user, I want receipts to be downloadable as PDFs with a distinct visual style
- As a user, I want receipts auto-numbered (REC-001, REC-002…)

### PDF Export
- As a user, I want to download professionally designed invoice PDFs
- As a user, I want the PDF to include my business branding, client info, line items, totals, and payment terms

### Client Management
- As a user, I want to save client information for reuse across multiple invoices
- As a user, I want to add, edit, and remove clients
- As a user, I want to see how many invoices I've issued to each client

### Business Profile
- As a user, I want to configure my business name, address, contact info, and tax number
- As a user, I want these details to appear automatically on all invoices
- As a user, I want to set default currency, tax rate, and payment terms

### Dashboard
- As a user, I want to see total revenue, outstanding amounts, invoice count, and client count at a glance
- As a user, I want a revenue chart for the past 6 months
- As a user, I want to see a list of recent invoices
- As a user, I want to be alerted to overdue invoices

## 4. Feature Specifications

### 4.1 Authentication
- Email + password registration and login
- Client-side validation
- Password requirements: minimum 6 characters
- Session persisted in localStorage
- Demo credentials pre-seeded: `demo@invoicepro.com` / `demo1234`

### 4.2 Invoice Creation
**Required fields:**
- Invoice number (auto-generated, editable)
- Issue date (default: today)
- Due date (default: today + payment terms)
- Client name (required)
- At least one line item with description

**Optional fields:**
- Client email, phone, address
- Currency (8 supported)
- Tax rate (%)
- Payment method
- Notes
- Terms & Conditions

**Auto-calculations:**
- Line item total = quantity × unit price
- Subtotal = sum of line item totals
- Tax amount = subtotal × (tax rate / 100)
- Grand total = subtotal + tax amount

### 4.3 Invoice Status Flow
```
Draft → Sent → Paid
              ↗
   Sent → Overdue (auto, when past due date)
```

### 4.4 PDF Generation
**Invoice PDF:**
- Dark blue header with business branding
- Client info section
- Itemized table (jsPDF autoTable)
- Totals block (subtotal, tax, total)
- Payment info, notes, terms
- "Generated by InvoicePro" footer

**Receipt PDF:**
- Emerald green header (distinct from invoice)
- "PAYMENT CONFIRMED" banner
- Same line items and totals
- Receipt number (REC-XXX format)

### 4.5 Dashboard Analytics
- Total Revenue (sum of paid invoices)
- Outstanding (sum of sent + overdue)
- Total Invoices count
- Total Clients count
- Monthly revenue bar chart (6 months)
- Invoice status breakdown (Draft / Sent / Paid)
- Recent invoices table (last 5)
- Overdue alert banner (if applicable)

### 4.6 Data Persistence
- All data stored in localStorage with `invoicepro_` prefix
- Per-user data isolation using user ID as key suffix
- Automatic demo data seeding on first load

## 6. Technical Architecture

### Stack
| Layer | Technology |
|-------|-----------|
| Framework | React 18 |
| Bundler | Vite 5 |
| Styling | Tailwind CSS 3 |
| Routing | React Router v6 |
| State | React Context API |
| Storage | localStorage |
| PDF | jsPDF + jspdf-autotable |
| Charts | Recharts |
| Icons | Lucide React |
| Dates | date-fns |

### Architecture Pattern
- **Context-based state management** — AuthContext for session, AppContext for business data
- **Single-user multi-account** — multiple users supported via localStorage namespacing
- **Derived state** — invoice status, totals, and stats computed on the fly (no stale caches)
- **Client-side PDF rendering** — no server required, instant generation

### Security Considerations
- Passwords stored in localStorage (acceptable for MVP demo; upgrade to hashed/server-side for production)
- No external API calls — fully offline capable
- No sensitive data transmitted over the network
- Per-user data isolation
